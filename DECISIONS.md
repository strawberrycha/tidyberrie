# Tidyberrie decisions

- **Runtime and focus** — Ship a private Android APK. Use the browser only for development and regression tests. Task Organizer is the current focus. Home and Tasks are enabled. Calendar and Budget keep their tabs and open placeholders. Day Theme is hidden. The flags affect access and reminder scheduling. Keep module code, data, and migrations intact.
- **Cleanup history** — Cloud sync and the installable web runtime were removed. Dexie v8 stores remain. Use the local checkpoint-before-cleanup tag or Git history for recovery.
- **CSP** — Keep script, style, fonts, images, and connections same-origin in production. Block frames, workers, and manifest loads. Firebase origins were removed. Use the embedded policy for the Capacitor local origin and a frame-ancestors header in development preview. Capacitor provides its native bridge ahead of the meta policy. Zod runs JIT-less. Browser-only notification fallback is for development.
- **Data and recovery** — Use IndexedDB, forward-only Dexie migrations, UUIDs, and soft deletion. Trash is retained for 30 days. Keep seven daily snapshots and a separate pre-restore safety snapshot. JSON is restorable and CSV is for inspection. Limit validated JSON to 10 MiB. Import previews are read-only and replacements are transactional. Confirm irreversible deletion by typing DELETE.
- **Local security** — Encrypt optional backups with AES-256-GCM, a random salt and nonce, and 600,000 PBKDF2-SHA-256 iterations. PIN verification uses separate salted PBKDF2 and retry throttling. App Lock blocks casual access. The local database is unencrypted. CSV wraps values and neutralizes spreadsheet formulas.
- **Legacy task data** — Keep v9 categories and estimates in storage and backups. Named schedules replace their UI. Map legacy `doing` to `in_progress` and preserve conflicting imported category names as archived.
- **Schedule storage** — Dexie v10 adds named schedules and per-task alert flags. Existing tasks remain independent and preserve their reminder offsets. Schedule tasks expand weekdays within inclusive local date bounds and use existing occurrence exceptions. Paused schedules produce no notifications. Use a 14-day one-shot window with a default cap of 256, below AOSP Android 16’s default 500 per UID. OEM limits and delivery timing need phone testing.
- **Task status** — Skipped tasks are closed and excluded from progress and overdue counts. Optional overdue tasks remain visible without increasing badges. Postponed tasks stay open. A later move preserves the original date and increments its count. A manual status change clears the original date. Repeating actions update only the selected occurrence. Task watches supply the existing reminder reconciliation with committed changes.
- **Task duplicate** — Copy the series and its fields, clear actual time and postpone history, and assign new unchecked subtasks. Clamp past dates to today and convert elapsed start times to all-day. Add a title suffix if the same date already has that title.
- **Dates and recurrence** — Store local calendar dates separately from timed values with offsets. Use RRULE weekday/week-start semantics and occurrence exceptions. Monthly rules skip months without the selected day. Annual February 29 repeats in leap years. End dates are inclusive. Subtasks reset each occurrence, and occurrence edits and skips preserve the original recurrence key. Reject past dates on create and moves into the past on edit. A new timed task with a reminder needs a future start time. Preserve unchanged overdue values and exempt import and restore.
- **Reminders** — Use three-second permission checks with retry and a first-use explanation. Reconcile the 14-day capped window against native pending IDs on data changes, launch, resume and local midnight. Preserve pending IDs during collisions. The native plugin restores alarms at boot. The high-importance channel uses Android’s default sound, vibration and private lock-screen visibility. Hidden modules contribute no reminders.
- **Android reminders** — Prepare with `npm run android:prepare` (build and sync). Use `USE_EXACT_ALARM` on API 33+ for this sideload-only APK and user-managed `SCHEDULE_EXACT_ALARM` through API 32. Reassess Google Play eligibility before any distribution. The local DeviceSettings plugin opens system settings with app details as fallback and exposes OS/app version and model for local diagnostics. No new dependency.
- **Budget** — Store integer centavos and use BigInt for exact aggregation. Derive funds from opening balances, received income, paid expenses, and transfers. Transfers affect neither income nor expense. LEFT cards include only outstanding items beyond current money. Monthly net includes all month activity. Safe-to-spend divides by remaining days or the next expected sahod. Settlement writes history once and recurring settlements substitute for their planned occurrences. Keep savings transfers, category limits, and utang ledger rules intact.
- **Design and accessibility** — Keep Strawberry Milk and Sakura Night, with optional palettes reserved as token sets. Keep local Nunito and Caveat, sticker fallbacks, keyboard access, contrast, 200% text, and reduced motion. Target 48dp phone controls when working on a module. Use the existing empty-state style for hidden tabs.

- **Shell dependency** — Use Capacitor App for the native back button and foreground clock refresh.

- **Home and navigation** — Greetings switch at 00:00, 05:00, 12:00, 17:00 and 21:00. Rotate 60 local-date quotes. Keep a three-day preview and the saved week start. At rollover, reset the strip to today. Budget mounts only when enabled and has a device-local amount mask. Restore tab scroll and pop within a tab before returning Home. Two Back presses within two seconds exit from Home.

- **Home reminders** — Use the bell for the single inbox and keep permission help in More. Missed uses the existing due fallback and excludes test alerts and times before task creation. Upcoming reads Android pending alerts in the next 24 hours. Remove the visible Home clock and retain the minute refresh for Next up.

- **Bulk tasks** — Use one Dexie transaction and one Undo for the exact previous records. The existing reminder watcher observes the commit. Schedule assignment applies to the series, and date and status apply to the displayed occurrence. An elapsed start blocks a scheduled occurrence move to today. Independent tasks become all-day and clear the timed reminder. Move all excludes optional tasks. Keep gestures secondary to visible controls.

- **Polish** — Gate the Tasks seed to browser development. Home lives in its own feature. New settings default to Sunday. Older Monday records lack a marker for explicit choice, so preserve saved values. Use sticky task chips and a draft filter sheet. Measure tab height and hide the FAB when the visual viewport reports a keyboard.
