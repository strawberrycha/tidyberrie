# Tidyberrie decisions

- **Runtime and focus** — Ship a private Android APK. Use the browser only for development and regression tests. Task Organizer is the current focus. Home and Tasks are enabled. Calendar and Budget keep their tabs and open placeholders. Day Theme is hidden. The flags affect access and reminder scheduling. Keep module code, data, and migrations intact.
- **Cleanup history** — Cloud sync and Firebase implementation were removed. The unused Dexie v8 stores retain their original definitions. Use the local checkpoint-before-cleanup tag or Git history to recover removed work. The installable web runtime, service worker, and manifest were removed. The APK ships its assets directly.
- **CSP** — Keep script, style, fonts, images, and connections same-origin in production. Block frames, workers, and manifest loads. Firebase origins were removed. Use the embedded policy for the Capacitor local origin and a frame-ancestors header in development preview. Capacitor provides its native bridge ahead of the meta policy. Zod runs JIT-less. Browser-only notification fallback is for development.
- **Data and recovery** — Use IndexedDB, forward-only Dexie migrations, UUIDs, and soft deletion. Trash is retained for 30 days. Keep seven daily snapshots and a separate pre-restore safety snapshot. JSON is restorable and CSV is for inspection. Limit validated JSON to 10 MiB. Import previews are read-only and replacements are transactional. Confirm irreversible deletion by typing DELETE.
- **Local security** — Encrypt optional backups with AES-256-GCM, a random salt and nonce, and 600,000 PBKDF2-SHA-256 iterations. PIN verification uses separate salted PBKDF2 and retry throttling. App Lock blocks casual access. The local database is unencrypted. CSV wraps values and neutralizes spreadsheet formulas.
- **Dates and recurrence** — Store local calendar dates separately from timed values with offsets. Use RRULE weekday/week-start semantics and occurrence exceptions. Monthly rules skip months without the selected day. Annual February 29 repeats in leap years. End dates are inclusive. Subtasks reset each occurrence, and occurrence edits and skips preserve the original recurrence key. Reject past dates on create and moves into the past on edit. A new timed task with a reminder needs a future start time. Preserve unchanged overdue values and exempt import and restore.
- **Reminders** — The queue incorrectly required Budget data even with Budget disabled, blocking permission checks and delivery. Use three-second permission checks with retry and a first-use explanation. Reconcile the 14-day capped window against native pending IDs on data changes, launch, resume and local midnight. Preserve pending IDs during collisions. The native plugin restores alarms at boot. The high-importance channel uses Android’s default sound, vibration and private lock-screen visibility. Hidden modules contribute no reminders.
- **Android reminders** — Prepare with `npm run android:prepare` (build and sync). Use `USE_EXACT_ALARM` on API 33+ for this sideload-only APK and user-managed `SCHEDULE_EXACT_ALARM` through API 32. Reassess Google Play eligibility before any distribution. The local DeviceSettings plugin opens system settings with app details as fallback and exposes OS/app version and model for local diagnostics. No new dependency.
- **Budget** — Store integer centavos and use BigInt for exact aggregation. Derive funds from opening balances, received income, paid expenses, and transfers. Transfers affect neither income nor expense. LEFT cards include only outstanding items beyond current money. Monthly net includes all month activity. Safe-to-spend divides by remaining days or the next expected sahod. Settlement writes history once and recurring settlements substitute for their planned occurrences. Keep savings transfers, category limits, and utang ledger rules intact.
- **Design and accessibility** — Keep Strawberry Milk and Sakura Night, with optional palettes reserved as token sets. Keep local Nunito and Caveat, sticker fallbacks, keyboard access, contrast, 200% text, and reduced motion. Target 48dp phone controls when working on a module. Use the existing empty-state style for hidden tabs.

- **Shell dependency** — Use Capacitor App for the native back button and foreground clock refresh.

- **Home and navigation** — Local greetings switch at 00:00 (Up late), 05:00 (morning), 12:00 (afternoon), 17:00 (evening) and 21:00 (night). Rotate 60 original local-date quotes. Use the existing week-window recurrence cache and show only a separate three-day preview. Follow the saved week start. If the date rolls over, return the strip to today. Budget amounts are masked by a device-local preference and the card only mounts when enabled. The FAB opens a single action directly. Keep mounted tab state, restore scroll, and pop locally before returning to Home. At Home, two Back presses within two seconds exit.

- **Home measurement** — Headless development Chrome at 390×844 with 1,000 seeded tasks measured 1,708 ms for the first Home render, including lazy loading and IndexedDB, and 264, 276, and 253 ms for week changes. These are browser observations rather than phone timings. Capacitor App is pinned at 8.1.2.

- **Polish** — Gate the Tasks seed to browser development. Home lives in its own feature. New settings default to Sunday. Older Monday records lack a marker for explicit choice, so preserve saved values. Use sticky task chips, a draft filter sheet, and the existing sort choices. Measure tab height and hide the FAB when the visual viewport reports a keyboard.
