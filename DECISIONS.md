# Tidyberrie decision log

## 2026-11-22

- **Decision** — Accept any supported Node.js LTS (22, 24, or 26). Develop on v24.20.0 and declare `engines.node` as `>=22` when creating `package.json`.
- **Reason** — Node.js v24.20.0 satisfies the supported-LTS requirement and is already installed.

- **Decision** — Store `Account.openingBalance` in integer centavos in the Phase 1 Dexie schema. Derive current balances from received income, paid expenses, and transfers between the user's accounts. Keep transfers out of income and expense totals. Record each Received or Paid transition once in `BudgetHistory` in the same transaction. Use only outstanding items in the LEFT cards, show monthly net separately, and divide LEFT THIS MONTH by the days remaining in the period or until the next expected sahod for the daily card. Cover each rule in Phase 5 unit tests.
- **Reason** — Deriving balances lets undo and deletion correct totals automatically. Using outstanding items for projections prevents received income and paid expenses already reflected in current balances from being counted twice.

### Phase 1 foundation

- **Toolchain** — Added `@tailwindcss/vite` for the official Tailwind CSS Vite integration, `@vitejs/plugin-react` for React transforms and Fast Refresh, `@types/react`, `@types/react-dom`, and `@types/node` for strict type checking, and `@eslint/js` for ESLint's recommended JavaScript rules. The manifest declares Node `>=22` as requested. Use an up-to-date patch of a supported LTS line because the pinned development dependencies have narrower engine ranges.
- **Contrast** — Darkened Strawberry Milk primary to `#B4375B` and muted text to `#74525F`. Completed Sakura Night's semantic palette with dark on-primary text. WCAG relative-luminance checks for used slots give minimum text, muted text, and primary button label ratios of 8.78:1, 6.11:1, and 5.77:1 in Strawberry Milk and 8.88:1, 7.80:1, and 8.23:1 in Sakura Night. Focus rings reach at least 4.79:1 and 5.48:1 against used surrounding backgrounds. Control outlines against the surface reach 4.61:1 and 4.89:1.
- **Backup** — Version 1 exports all tables, including snapshots. Snapshot contents exclude other snapshots to avoid recursive growth. Merge uses the imported copy when records match, and Replace requires typing `REPLACE`. Imports use a 10 MiB limit and run in one transaction. Storage persistence is checked on this device after import.
- **Scope** — Home, Calendar, Tasks, and Budget use empty states. Settings exposes Phase 1 controls. Dexie v1 contains the ten requested tables. Transfer storage and balance calculations are deferred to Phase 5.

### Phase 2 tasks

- **Dates and recurrence** — Use plain local calendar dates for recurrence keys and store timed fields with their local offset. Monthly rules skip months that lack the selected day, and February 29 repeats only in leap years. End dates are inclusive and the maximum count includes the first matching occurrence. Save the configured weekday as RRULE `WKST` when saving a series. Changing the setting alone preserves previously saved rules.
- **Occurrence editing** — Offer “This occurrence only” and “All occurrences.” Defer “This and following” because safely splitting a series requires reassigning its exceptions and preserving count limits. Occurrence edits can carry their own fields and subtasks. Completed, moved, and skipped dates keep their original occurrence keys. A skipped occurrence can be recovered through Undo. Trash shows whole deleted tasks and series.
- **Smart lists** — Today and Upcoming show open items. Upcoming covers tomorrow through seven days from today. Overdue includes open one-time tasks and browsable 30-day repeat windows. All and Pinned present one card per series, showing its next open occurrence when available.
- **Storage** — Dexie v2 adds an optional occurrence override and a `movedTo` index for destination-date queries. The v1 definition and existing rows remain intact. Former backups still validate because the new field is optional. Whole-task deletion, restore, and undo run in transactions. Undo rejects if the saved group has since changed in another action.
- **UI** — Use native modal dialogs and keyboard up/down buttons for subtasks. The four existing pink/peach accents are joined by lavender, mint, honey, and sky tokens. Accent strips are decorative. Status and priority use text plus icons. No packages were added.
- **Contrast** — Strawberry Milk and Sakura Night validation text on the dialog surface measured 5.44:1 and 7.48:1. Status and priority text on the soft background measured 9.94:1 and 9.22:1. Selected list chips and primary buttons use the existing on-primary pairs at 5.77:1 and 8.23:1.
- **Performance** — Headless Chrome against Vite dev at 1280×900 measured 797 ms from starting the seed through showing the first page of 1,000 mixed-rule tasks. The page rendered 20 cards at a time. Click-to-observed-update timings were 214 ms for Today, 231 ms for Upcoming, 218 ms for Overdue, 141 ms for All, and 117 ms for the next page. These single-run timings include DevTools polling and development overhead. Task relationships use indexed lookups, list calculations are memoized, and recurrence expansion uses bounded list windows.
